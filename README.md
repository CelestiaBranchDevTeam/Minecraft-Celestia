# Minecraft-Celestia
Minecraft Celestia is a branch of Alpha 1.2.6, made to improve my java skills.

To Play Celestia:

1. Use Betacraft or MultiMC (Betacraft recomended)

Betacraft Download: https://betacraft.uk/downloads

1. Once you get betacraft installed, set it up and log into your minecraft account
2. Make a new instance (or use the default one)
3. Take the minecraft.jar from Celestia and go to C:\Users\computername\AppData\Roaming\.betacraft\versions
4. Put the minecraft.jar in there
5. Restart Betacraft
6. Click on Select Version
7. It should be at the bottom, click on it and youre ready to play!

MultiMC Download: https://multimc.org/#Download
1. Download and setup MultiMC with your minecraft account
2. Click add instance on the top left
3. Scroll down to Alpha 1.2.6 (click on the Alphas option in the filter to the right if you cant find it) Click OK
4. Go to Edit Instance
5. Click to Replace Minecraft.jar and select the minecraft.jar from Celestia
6. Click play, and youre in the game!
